# Getting help

- **Usage questions:** read the [README](README.md) first, including the
  per-platform guarantees. Then open an issue using the bug report template if
  the behavior does not match.
- **Bugs:** use the
  [bug report template](https://github.com/open-source-collabs/work_vault/issues/new?template=bug_report.md).
  Include the platform, the `work_vault` and Flutter versions, and steps to
  reproduce.
- **Feature requests:** use the feature request template.
- **Security issues:** do not open a public issue; follow [SECURITY.md](SECURITY.md).

Only the latest published minor version is supported.
