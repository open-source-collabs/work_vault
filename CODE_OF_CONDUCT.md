# Code of conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Read it there; it applies to every space where the project is discussed:
issues, pull requests, and discussions.

In short: be respectful, assume good faith, and keep feedback about the work,
not the person. Harassment, personal attacks, and discriminatory language are
not acceptable.

## Reporting

To report a violation, contact the maintainers privately through the
maintainers' GitHub profiles listed in [CODEOWNERS](.github/CODEOWNERS). Do not
use a public issue. Reports are handled confidentially, and maintainers may
remove comments or restrict participation to protect the community.
